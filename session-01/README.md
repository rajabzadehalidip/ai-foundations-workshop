# AI Foundations Workshop — Session 01

This folder contains all materials for the first three-hour session: AI foundations, LLMs, APIs, local models, and embedding-based analysis.

## Start here

1. Open `index.html` in a browser for the editable presentation. Press `E` to edit text, add or duplicate slides, and download an edited copy.
2. Use `telegram_policy_radar_4topics_openrouter_colab.ipynb` for the main hands-on activity. Students upload `telegram_policy_radar_4topics_fa.csv` and use an OpenRouter embedding model to explore four policy topics.
3. Read `telegram_policy_radar_4topics_openrouter_guide.md` for facilitation notes for the Telegram Policy Radar activity.

## Main materials

- `index.html` — editable Session 01 presentation.
- `ali-photo.png` — presenter photo used by the Session 01 presentation.
- `telegram_policy_radar_4topics_openrouter_colab.ipynb` — English-language Google Colab for API-based embeddings, classification, PCA mapping, semantic search, and a human-review queue.
- `telegram_policy_radar_4topics_fa.csv` — cleaned, unlabeled 160-post Persian Telegram dataset for the hands-on activity.
- `telegram_policy_radar_4topics_openrouter_guide.md` — facilitator guide for the main activity.
