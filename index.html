2 · Short history

The path to modern AI

1950

Turing test

A behavioral test: can a machine imitate human conversation?

1966

ELIZA

Pattern matching and templates created an impression of understanding.

1980s–90s

Expert systems

Knowledge encoded as rules; powerful but brittle and expensive to maintain.

2013

word2vec

Words became vectors: meaning as geometry from contextual use.

2017

Transformers

Attention made long-range context and scale practical.

2018+

GPT

Large-scale next-token prediction became a general language interface.

Today

Multimodal AI

Text, images, audio, code, tools, and agents.

Key idea

Patterns at scale

Most present capabilities are downstream of learning from data.

2 · Short history

What changed from ELIZA to LLMs?

ELIZA

  • Human-written patterns
  • Fixed response templates
  • No learned representation
  • Breaks outside anticipated phrases

Large language model

  • Learned parameters from huge corpora
  • Context-sensitive token representations
  • Generates novel continuations
  • Flexible—but can still be wrong

The model became more flexible, not automatically more truthful.

2 · Short history

Embeddings: the bridge from text to computation

Words, sentences, and documents can be represented as vectors. Similar meanings tend to occupy nearby regions.

“market power”       → [ 0.18, -0.42, 0.77, … ]
“ability to raise prices” → [ 0.16, -0.39, 0.74, … ]

similarity → high

Why researchers care

Once text becomes vectors, we can search, cluster, classify, deduplicate, recommend, and visualize large corpora.

4 · How LLMs work

An autocomplete trained on a planet of text

An LLM does not look up “the answer.” It estimates what token is likely to come next given the context.
Prompt
“The regulator announced a new…”
→
Probabilities
policy · rule · framework · plan
→
Pick token
one continuation
→
Append
then predict again
4 · How LLMs work

The loop in miniature

context = “Competition policy should protect”

P(next token):
  consumers   0.41
  competition 0.24
  markets     0.13
  workers     0.05
  ...

choose “consumers”
context = “Competition policy should protect consumers”
repeat until the answer stops

Temperature

Changes how conservative or varied the selection is. It does not turn a false statement into a true one.

Why hallucination happens

The training objective rewards plausible continuation, not independent verification of every claim.

4 · Model controls

The parameters students will meet

ControlWhat it changesPractical intuition
TemperatureRandomness of token selectionLower for consistent extraction; higher for brainstorming
Max tokensMaximum length of the generated responseControls cost and prevents runaway answers
Context windowHow much input plus output the model can handleLong documents still need chunking and retrieval
System roleHigh-level behavior and constraints“You are a careful research assistant…”
User roleThe task, question, or document supplied at runtime“Classify this paragraph and cite the evidence”
These controls improve the workflow, but they do not create evidence or guarantee factual accuracy.

5 · Why tools are not enough

The convenience–control trade-off

ProblemWhat it means for a think tank
Black boxIt may be unclear which model, prompt, retrieval process, or data policy produced the result.
Limited controlYou cannot always set the output schema, evaluation set, model version, or review threshold.
Changing limitsFree plans, rate limits, features, and prices can change.
Data governanceConfidential or sensitive material may not be appropriate for a consumer tool.
Weak reproducibilityA result may be difficult to reproduce six months later.
Vendor dependenceYour workflow becomes tied to one interface or provider.
5 · Why use LLMs directly?

When direct access gives us more leverage

Cheaper at volume

For repetitive extraction, an API can process many rows with a small, fixed prompt and no manual copy-paste.

More control

Choose the model, prompt, output schema, sampling, logging, and evaluation set.

More flexible

Connect models to spreadsheets, databases, search, code, and internal workflows.

More transparent

Record inputs, outputs, versions, errors, cost, and human corrections.

Direct access does not automatically make a system open or transparent—but it makes those properties possible to design.

Treat an API key like a password: use a secret manager or environment variable, set a budget, and never commit it to a notebook or Git repository.
5 · Cost and deployment

A simple cost comparison

Hosted API

Pay per input/output token or request. Usually easiest to start and often inexpensive for screening or extraction.

Trade-off: provider dependency, network transfer, usage charges, and policy constraints.

Open model locally

No per-token provider bill once installed; can be useful for repeatable or sensitive experiments.

Trade-off: hardware, setup, maintenance, speed, and model quality.

Exact prices change. Teach the method: estimate tokens × price, compare with hardware and staff time, and measure quality—not just cost.

7 · Embeddings

What an embedding model does

It converts text into a vector: a list of numbers that captures useful patterns of meaning.

“barriers to entry” → [0.12, -0.44, 0.73, …]
“obstacles for new firms” → [0.10, -0.41, 0.70, …]

cosine similarity → high

Useful operations

  • Semantic search
  • Clustering
  • Nearest-neighbour classification
  • Duplicate detection
  • Corpus visualization

7 · Closing the lab

Questions after the experiment

  • Which categories were confused, and why?
  • Did the embedding model capture the distinction our research question needs?
  • What would we add to each row for traceability—document ID, page, jurisdiction, date, quotation?
  • Would this be safe for triage? Drafting? A published conclusion?
  • What would change if the corpus were multilingual or much larger?
Never confuse a neat visual cluster with a validated research finding.
